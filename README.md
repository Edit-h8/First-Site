# 🌐 My First Django Website

This is my **first website built with Django**.

It started as a project where I wanted to learn how Django actually works beyond simple tutorials and examples. While building it, I gradually added more features, fixed a lot of bugs, changed things, broke things again 😅, and learned a lot from the process.

This project is not meant to be a perfect or production-ready website.

**It is simply where my Django journey started.**

---

## 🚀 What does this project include?

Even though this was my first Django website, I tried to make it more than just a basic project.

Some of the things I implemented include:

* 🔐 User authentication with **django-allauth**
* 🔑 Password reset
* 👤 User account management
* 🗺️ XML Sitemap
* 🌐 Multiple pages and URL routes
* 🛡️ Authentication-based views and permissions
* 📝 Forms and form handling
* 💬 Django messages
* 🎨 Custom HTML & CSS
* 🐍 Django backend logic
* 🗄️ Database models and Django ORM
* 📱 Responsive page structure
* ⚙️ Django settings and project configuration

And probably a few other things that I forgot to mention here.

## 📚 What I Learned

This project taught me much more than just how to write Django code.

I learned how different parts of a real web application connect together — from URLs and views to templates, models, authentication, emails, databases and deployment-related configuration.

I also learned something equally important:

> Building a project is a lot different from watching someone else build one.

A lot of the things I learned came from making mistakes, reading errors, searching for solutions, changing my code, and trying again.
